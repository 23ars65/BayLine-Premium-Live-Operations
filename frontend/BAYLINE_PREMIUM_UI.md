# BayLine Premium UI

This version keeps the existing Supabase data model and booking logic while upgrading the frontend:
- responsive premium automotive UI
- animated navigation and cards
- interactive branch map using real latitude/longitude values
- map search/state filtering inside booking
- service cards and live slots
- booking confirmation animation
- redesigned customer dashboard, login, and staff/admin board
- reduced-motion support

Run:
1. npm install
2. npm run dev

The existing `.env` configuration is preserved. Do not commit secrets.
